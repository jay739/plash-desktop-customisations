# Contributing to plash-desktop-customisations

Thanks for considering a contribution. Issues, discussions and PRs are all
welcome.

## Getting set up

Add your style as a folder (`Style N/`) with its `.css`, `.js` and a preview `.png`, and add a row to the Styles table in the README naming the website it targets.

## Running the checks

CI runs `node --check` on every script and checks that README images exist. Load the style in Plash and confirm it looks right before opening a PR.

## Ground rules

- Open an issue or discussion before large changes, so effort isn't wasted.
- Keep PRs focused: one change per PR.
- New behavior needs a test where the repo has a test suite.
- CI must pass before merge.
